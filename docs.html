Snaptext and SnapText Rx

Everything you need to install, use and activate Snaptext, the Handwriting Pack and SnapText Rx. The printable user guides cover the same steps.

System requirements

ItemNeeded
WindowsWindows 10 or 11, 64-bit
BrowserMicrosoft Edge (built into Windows) or Google Chrome. It only draws the app window and never goes online.
RightsAdministrator rights to install
DiskSnaptext about 350 MB · Handwriting Pack about 450 MB · SnapText Rx about 1.3 GB
Graphics cardNot needed. Everything runs on the CPU.
InternetNot needed after download

Install

  1. Download Snaptext-Setup.exe and run it.
  2. If Windows shows "Windows protected your PC", click More info → Run anyway. The installers aren't code-signed yet. You can check the file against the SHA-256 hash on the releases page.
  3. Click Install, then launch Snaptext from the Start menu. It opens in its own window.
  4. Optional: run Snaptext-Handwriting-Pack.exe to add handwriting. Use the pack from the same release as Snaptext.

SnapText Rx installs the same way from SnapText-Rx-Setup.exe. You'll accept the intended-use terms during install. It installs next to Snaptext without affecting it.

Offline installation (air-gapped PCs)

Everything is inside the installers, including the OCR engine, the models and the Visual C++ runtime.

  1. On a PC with internet, download the installers and SHA256SUMS.txt from the releases page.
  2. Copy them to a USB drive or network share, then to the offline PC.
  3. Check each file on the offline PC. The result must match the hash in SHA256SUMS.txt: 
    certutil -hashfile "Snaptext-Setup.exe" SHA256
  4. Install as above. To activate offline, see Get and activate a licence.

Your first scan

  1. Open Snaptext. You're on the Scan screen.
  2. Drag a PDF or image onto the window, or press Ctrl+V to paste a screenshot.
  3. The text appears on the right. Click Copy or Download.

Scan files

Snaptext reads PDFs and images (PNG, JPG and other common formats). Drop several files at once, or click Browse. Each page is shown with the lines it found, so you can check what was read.

Snip a region

  1. Click Snip a region on the Scan screen. Snaptext tucks itself away and counts down.
  2. Bring up the window you want, then draw a box around the text.
  3. The text comes back into Snaptext and is copied to the clipboard.

Lens hotkey

Lens works from any app, without opening Snaptext first. It only needs to be running.

  1. Press Ctrl+Alt+L. If another app already uses it, Snaptext picks another shortcut and shows it in the app.
  2. Drag a box over the text. It's read straight away. Drag the box to move it, drag its edges to resize it, or nudge it with the arrow keys. It reads again each time.
  3. Optional: click individual lines to pick only those, or press Ctrl+A to pick all.
  4. Press Ctrl+C or double-click inside the box to copy the text. Press Enter to open it in Snaptext instead, or Esc to cancel.

OMR answer sheets

OMR (optical mark recognition) reads filled bubble sheets, such as exam answers, surveys or attendance.

Make a sheet

  1. Open the OMR screen.
  2. Set the title, number of questions, options per question (2–9) and roll-number digits.
  3. Click to create the sheet and print the PDF. A code along its edge tells Snaptext the layout, so any sheet you made can be read later.

Read and mark sheets

  1. Scan the filled sheets, then drop the images or PDF on the OMR screen. Several sheets at once is fine.
  2. Enter the answer key, e.g. ABCDA BCDAB … or 1-A, 2-C, 3-B, with - to skip a question. Or fill in one sheet with the correct answers, read it and use it as the key. Negative marking is optional.
  3. Export every sheet's roll number, answers and score as CSV.

Handwriting Pack

The free pack adds a Handwriting option on the Scan screen. Snaptext finds each line, the handwriting reader reads it, and each line gets its own confidence.

  • It's trained on English handwriting. Neat handwriting reads best.
  • It reads one line at a time, so long pages take longer than printed text.
  • Always check important text against the original.

Command line

The installer adds the snaptext command to your PATH. The trial, the daily limit and your licence apply here too.

snaptext region          # draw a box on screen, OCR it, copy the text
snaptext window          # OCR the active window
snaptext screen          # OCR the monitor under the mouse
snaptext clipboard       # OCR an image already on the clipboard
snaptext file a.pdf b.png --out results\   # OCR files to Markdown
snaptext watch           # hotkeys: Ctrl+Alt+O region, +W window, +S screen, +Q quit
snaptext ui              # open the Snaptext window

Add --append report.md to build a report from several captures, or --history to keep every capture.

SnapText Rx: overview and safety

SnapText Rx reads a photo, scan or screen snip of a prescription, including handwriting, and turns each medicine line into a card. Each card shows the medicine, strength, form, dose, frequency, duration and instructions. Everything runs on your PC, so prescriptions and patient details never leave it.

Intended use. SnapText Rx is a transcription aid. It is not a medical device and not a clinical decision tool. It doesn't check doses, interactions, allergies or whether a prescription is appropriate. A pharmacist or trained person must check every line against the original prescription.

Reading a prescription

  1. Drop a photo or scan on the left panel, paste a screenshot, or snip it from the screen.
  2. Each medicine line is read by two handwriting readers, taking about two seconds per handwritten line.
  3. On the right, each medicine has a card with the crop of the handwriting next to what was read. Check it against the crop.
  4. Click ✓ Confirm on each card. Mark lines that aren't medicines as Not a medicine.
  5. Enter your name under Checked by. Copy as text, CSV and JSON unlock only then.

Changing a confirmed card un-confirms it, so nothing you haven't checked is exported. Every export records the checker's name, the date and time, and each line as it was read.

What each status means

StatusMeaningWhat to do
In drug listThe word read is exactly a known medicine, and both readers agree.Compare with the handwriting, then confirm.
Suggested — checkThe word read is close to one known name, which is filled in. The word as read is shown above it.Check carefully, and change it if it's wrong.
Look-alike — chooseTwo or more medicines are about equally close (e.g. Hydroxyzine / Hydralazine), or the readers disagree. Nothing is filled in.Pick the one on the prescription. It's usually the first button.
Unsure — pick or type itNo match is close enough to fill in. Possible names are shown as buttons only.Type the medicine. The box suggests names as you type.

My formulary

The built-in list has about 4,800 medicine names. Adding the brands you stock makes more lines come back as In drug list.

  1. Click My formulary on the left.
  2. Add your brand names, one per line, e.g. Panadol Extra.
  3. Click Save. They're used from the next prescription onwards.

Tips: photograph the prescription flat, in good light, filling the frame. Read one prescription per image. English and Latin-script medicine names are read; Urdu text isn't.

Accuracy

We measured on two public datasets of real handwritten medicine words from Bangladeshi prescriptions. None of these images were used for training. Each image was read exactly as a snip would be, with the dataset's medicine names entered as the formulary.

Test setWordsRight medicine firstRight medicine offeredShown confidently but wrong
RxHandBD test split1,11062.8%77.7%1.1%
Doctor's Handwritten Prescription BD (other hospitals)77982.1%87.4%1.4%

About 70% of rows come back as Look-alike — choose, because many local brands look alike. The right name is usually the first choice, so it takes one click. Real doctors' handwriting varies, so measure on your own prescriptions before relying on these numbers.

The licence badge at the top of the app shows your current state. A Snaptext licence unlocks Snaptext and the Handwriting Pack. SnapText Rx has its own licence.

Get and activate a licence

  1. Find your Machine ID. Click the licence badge (Trial or Free). Copy the ID under Your Machine ID, e.g. ABCD-1234-EF56-7890.
  2. Request the licence. Use the licence request form. It prepares an email with your Machine ID(s) for you to send. For an offline PC, copy the ID by hand or USB and send it from any computer.
  3. Pay. We reply with the amount and payment details.
  4. Receive the licence. After payment we email a .qslic file for each PC.
  5. Activate. Open the .qslic file in Notepad and copy everything, including the BEGIN and END lines. Paste it into License key under the licence badge and click Activate. The badge changes to Licensed.

IT administrators: to activate for every user of a PC, copy the .qslic file into C:\ProgramData\Snaptext\ (or C:\ProgramData\SnapText Rx\) and restart the app.

Several PCs

Each licence is signed for one PC. Put every Machine ID in the request form, one per line, and you'll receive one file per PC. For a school, hospital or company, choose Site licence in the form and we'll send a quote.

New PC or Windows reinstall

Reinstalling or updating Snaptext keeps the same Machine ID, so your licence keeps working. If asked, paste it again. A new PC or a fresh Windows install gives a new Machine ID. Email us or WhatsApp us the old and new IDs.

Privacy and security

  • Offline: no network connections, no cloud, no telemetry, no account.
  • Signed licences: licences are signed with Ed25519 and checked on your PC, so they can't be forged or edited.
  • Tamper protection: the app's code is compiled to native code and sealed. A changed file stops the app from running, and a changed handwriting model is refused.
  • Local data: the trial state and licences are stored in %LOCALAPPDATA%\Snaptext (or SnapText Rx).
